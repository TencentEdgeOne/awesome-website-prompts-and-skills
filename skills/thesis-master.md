## 📝 作品介绍

Thesis Master - AI 学术写作助手
    
基于 Next.js 16 的全栈 AI 学术写作平台。支持一键游客登录、论文项目管理、章节结构写作、AI 对话辅助。技术栈：Next.js 16 + React 19 + Tailwind CSS 4 + SQLite + JWT + OpenAI。特点：开箱即用、本地 SQLite 无需配置、深色主题界面、完整 RESTful API。

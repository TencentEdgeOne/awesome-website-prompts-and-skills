## 📝 作品介绍

## Academic Hub Skills v1

**核心价值**：一键生成完整的学术论文管理前端项目，从脚手架搭建到云端部署全链路覆盖，让研究者零前端基础也能快速拥有专属学术空间。

**适用场景**：
- 个人文献管理与知识沉淀
- 实验室/课题组论文追踪
- 学术项目进度可视化
- AI 辅助文献综述与研究

**亮点功能**：
- **5 种主题预设**：科技机甲、极简学术、温暖书院、赛博朋克、星空深海，一键切换
- **30+ 真实论文 Mock 数据**：开箱即用，无需额外配置
- **双模式 API 架构**：Mock 模式快速原型 / 真实后端无缝切换
- **EdgeOne 一键部署**：内置部署脚本，分钟级上线
- **React 19 + Vite 8 现代栈**：TypeScript 全类型覆盖，生产级代码质量

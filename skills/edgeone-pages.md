## 📝 作品介绍

摘要 — EdgeOne Pages 全栈站点能力
名称： EdgeOne Pages 全栈站点能力 (edgeone-pages-fullstack-site)

核心价值： 将“一句话需求”转化为一个完整、可部署的商业网站。该能力引导 AI Agent 构建基于 React + Vite + Tailwind 的前端，以及基于 EdgeOne Pages 的模块化后端（包含边缘函数 Edge Functions、云函数 Cloud Functions、中间件 Middleware 及 KV 存储）。它通过可选模块无缝集成 身份认证 (Auth)、电子商务 (Commerce)、支付 (Pay)、AI 助手和管理后台 (Admin Dashboard)，并最终交由 edgeone-pages-deploy 实现一键上线。

适用场景：

独立开发者： 在一下午时间内交付 MVP 电商或付费内容网站。

SaaS / 内部工具： 快速搭建具备登录、AI 及管理后台的工具，无需处理底层架构对接。

知识付费与会员制站点： 整合身份认证、支付系统与 AI 能力的综合站点。

团队原型开发： 在 EdgeOne 边缘侧快速验证商业化流程。

核心亮点：

🚀 从一句话到全栈： 输入一句话需求即可生成本地可运行、全球可部署的全栈站点。

🧩 高度模块化： 按需选择功能模块，杜绝冗余代码。

⚡ 边缘原生认证： 基于 Web Crypto JWT 实现，零 npm 依赖，确保延迟低于 100 毫秒。

💳 支付集成： 预置 Stripe 支持，并提供支付宝/微信支付扩展接口。

🤖 AI 助手： 支持多种大模型 (LLM-agnostic)，内置 RAG（检索增强生成）及“意图到行动”的任务流对接。

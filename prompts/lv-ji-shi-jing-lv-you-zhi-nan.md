## 📝 作品介绍

作品介绍
作品名称： 旅迹 · 实景旅游指南

核心价值： 让旅游探索回归地理直觉——在地图上点击，景点就在眼前。告别刷列表、翻攻略的繁琐，用最自然的交互方式发现目的地。信息来源于真实游客体验，而非商家推广，让旅行决策更真实可靠。

适用场景：

🗺️ 旅行灵感发现：随意点击地图，探索未知省份的景点
📍 目的地初筛：快速了解某省有哪些值得去的地方
📱 旅途中的离线参考：完全离线可用，无网环境也能查看景点信息
🎓 地理文化学习：交互式地图直观展示省市行政区划与景点分布
亮点功能：

两级地图交互：中国地图→点击省份→GeoJSON市区地图→点击景点，层层深入，地理直觉驱动
3D等高线视觉：市区地图采用同色系深浅渐变+三层浮雕滤镜，立体感强，一眼区分地形
脉冲景点标注：五A/网红景区用双层脉冲光点动态标注，视觉引导明确
全国475市区覆盖：33省GeoJSON数据全内置，完全离线，0网络依赖（考虑在线网络模式）
移动端触控优化：双断点响应式+触控热区放大+touch弹窗，手机体验流畅
智能市名标注：自动缩写长名+白色描边+面积自适应字号，信息密度与可读性兼顾

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.

创建一个名为"旅迹"的交互式中国旅游指南网站，要求如下：

【核心功能】
- 首页展示SVG中国地图，支持点击省份进入详情
- 省份详情页展示GeoJSON市区交互地图，所有市区名称直接标注在地图上
- 景点用脉冲光点标注在市区地图上，点击显示景点信息卡片（名称、简介、评分、图片）
- 支持从省份详情返回首页的导航

【视觉设计】
- 地图配色：省份用胭脂浅红(#F5E6E0)，市区用红粉等高线渐变(#f8e8e4→#5e180e)，地图外区域浅灰白(#FAFAFA)
- 主色调：--primary: #c06060，标题文字深红棕(#4a3030)
- 地图3D浮雕效果：外阴影+左上高光+右下暗角三层滤镜
- 市区hover浮起+亮度提升+胭脂色外发光
- 景点脉冲动画：双层脉冲圈(24px/28px)+核心点发光
- 页面切换使用弹性曲线 cubic-bezier(0.16，1，0.3，1)

【数据结构】
- 省份地图：内置SVG path数据(viewBox 800x700)
- 市区地图：内置GeoJSON数据(33省475市区)，支持离线使用
- 景点数据：按省份组织，包含景点名称、坐标、简介、评分、标签
- 智能市名缩写：去掉"市/地区/自治州"等后缀，长名特殊映射(如"克孜勒苏柯尔克孜自治州"→"克州")

【响应式与交互】
- 768px/480px双断点适配，移动端触控优化
- 使用100dvh避免手机地址栏遮挡
- 触控设备增大点击热区，touchstart显示完整市名
- 有数据的省份添加呼吸光效提示，首页底部显示引导文字
- 海南岛特殊处理：去掉南沙群岛，主岛放大1.3倍
- 香港澳门添加透明热区圆增大可点击范围

【技术要求】
- 纯前端HTML/CSS/JS单文件实现，无框架依赖
- 所有数据内嵌，完全离线可用
- GeoJSON数据覆盖全国33省475个市区
- 字体：微软雅黑，简约高级风格
```

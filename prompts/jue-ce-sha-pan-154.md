## 📝 作品介绍

决策沙盘 - 创业者决策助手

核心价值：帮助创业者在关键决策时刻（选赛道、定价、产品方向），用认知工具看清本质、找到方向。

适用场景：创业者、独立开发者、需要做关键决策的人。

亮点功能：
1. 降维提取机 - 从复杂局面中提取3个关键变量
2. 思维圆桌会 - 召唤历史人物模拟决策辩论
3. 决策时间线 - 可视化决策路径和后果

视觉特色：深色主题 + 霓虹渐变 + 粒子动画 + 玻璃态卡片

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
Create a visually stunning， dark-themed single-page website for "Decision Sandbox" - a decision support tool for entrepreneurs.

## Goal
Build a concept showcase website with:
- Hero section with particle background and animated ASCII art
- Problem section with 3 glassmorphism cards
- Three cognitive tools showcase with interactive demos
- Example decisions with tab navigation
- CTA section with neon glow effects

## Technical Stack
- React 18 + TypeScript + Tailwind CSS
- Framer Motion for animations
- Dark theme with neon accents (#00d4ff， #8b5cf6， #10b981)
- Glassmorphism effects
- Particle background animation

## Brand Rules
- Deep black background (#0a0a0f)
- Neon gradient text for headings
- Glowing interactive elements
- JetBrains Mono for code/ASCII
- Smooth 60fps animations

## Layout
- Full-viewport hero with particle background
- 3-column grid for tools (responsive)
- Tab navigation for examples
- Mobile-first responsive design

## Features
- Interactive tool demos (mock functionality)
- Animated ASCII art with typing effect
- Smooth scroll and reveal animations
- Particle background with subtle movement

Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.

```

## 📝 作品介绍

作品名称
NEXUS AI - 高端科技品牌官网
核心价值
通过精心设计的 Prompt，一句话生成 Awwwards 级高端官网。作品展示了 Prompt 工程在 AI 建站领域的极致潜力——同样用 AI 建站，我们追求的是质感和差异化，而非模板套用。

 适用场景
- AI/科技创业公司品牌官网
- 高端定制化网站快速原型
- Prompt 工程能力展示

亮点功能
- 极简奢华风格：深色主题 + 香槟金点缀
- 动态粒子星空背景（Canvas）
- 数字滚动计数动画
- 卡片悬浮 3D 效果
- 滚动触发动画（Intersection Observer）
- 毛玻璃导航栏
- 表单验证 + 提交动画
- 响应式适配（桌面/平板/手机）

一句话介绍：用一句 Prompt，造一座 Awwwards 级高端科技官网。

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
【角色】你是一位顶级品牌设计师和前端工程师，曾服务于苹果和特斯拉等国际品牌。
【任务】为一家人工智能科技公司创建官网，要求达到 Awwwards 年度最佳网站水准。
【设计规范】
- 风格：极简奢华 × 科技未来感
- 主色：深邃黑 #0a0a0a，辅以香槟金 #d4af37 和电光蓝 #00d4ff
- 字体：主标题 Playfair Display，正文 Inter，代码 JetBrains Mono
- 动效：缓动函数 ease-out，主色调过渡 0.4s，滚动触发 fade-up
【页面结构】
1. 导航栏：Logo + 菜单 + CTA按钮，毛玻璃效果
2. Hero区：全屏渐变 + 动态3D文字 + 粒子星空背景
3. 数字展示：统计数据滚动计数动画
4. 特色服务：卡片悬浮3D翻转效果
5. 团队介绍：头像悬停放大 + 光晕效果
6. 客户评价：轮播 + 淡入淡出
7. 联系方式：表单验证 + 提交动画
8. 页脚：社交图标 + 版权信息
【技术要求】
- 纯原生 HTML5 + CSS3 + Vanilla JS
- 无框架依赖，单文件实现
- Lighthouse 性能评分 ≥ 95
- 语义化标签，可访问性 AA 标准
【输出】Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.

```

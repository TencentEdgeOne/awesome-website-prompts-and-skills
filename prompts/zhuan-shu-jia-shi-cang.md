## 📝 作品介绍

作品名称：专属驾驶舱 — 打工人的 AI 多功能聚合工作台
核心价值： 一句话 Prompt 生成 12 个实用模块的私人工作台，零代码、零后端、纯前端离线运行，隐私数据不离开浏览器。
适用场景：上班族日常办公辅助——日历管理、求职追踪、灵感记录、健康提醒、摸鱼解压、命理运势查询，一站式聚合。
亮点功能：
1. 🦞 桌面宠物龙虾 + 星空粒子 + 对话气泡，开机即陪伴
2. 🔮 八字命理自动排盘（四柱·十神·五行·流年·星座·老黄历）
3. 📌 毛毡板灵感舱（日记/吐槽/灵感/备忘，图钉纸张 + 标记置顶主页）
4. 👥 多用户密码登录，SHA-256 加密，数据完全隔离
5. ⚙️ 工作导览自定义：待办/提醒/便签/喝水状态自由开关
6. ⚙️ 模块导航自定义拖拽排序
7. 🌤 天气 + 实时新闻 + 劳动法速查 +  AI 教程 + 成长路径 + 求职 CRM

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.

请帮我制作一个「个人专属驾驶舱」网页系统，这是一个打工人日常使用的多功能聚合工作台。要求如下：

整体风格：
- 深色太空主题，背景使用深蓝-深紫渐变，点缀星空粒子
- UI 走极简科技感路线，卡片使用毛玻璃效果，圆角 14-20px
- 主色调：冰蓝 #5eb8e6，辅助色：浅青 #6fc4d8、淡紫 #b388ff
- 字体清晰大方，保护视力，采用护眼柔和灰蓝色系

架构设计：
- iframe 外壳架构：shell.html 作为主容器，所有模块以独立 HTML 子页面嵌入
- 子页面通过 parent.navigate() 与外壳通信
- 数据全部使用 localStorage 本地持久化

包含以下 11 个功能模块：
1. 首页Hub — 模块导航入口，实时时钟，下班倒计时，自定义工作导览，模块排序
2. 命理舱 — 八字四柱、十神分析、五行仪表盘、星座运势、老黄历
3. 摸鱼舱 — 计时器、转盘、摸鱼借口、布谷鸟钟、精神状态
4. 健康舱 — 喝水环形进度、起身舒展、久坐提醒
5. 工作舱 — 日历、考勤提醒、每月待办清单、任务追踪
6. 金钻舱 — 求职平台聚合（Boss/猎聘/智联）
7. 早报舱 — 实时新闻、劳动法案例、AI动态
8. 学习舱 — 劳动法速查、AI教程、成长路径
9. 灵感舱 — 毛毡板风格日记/吐槽/灵感/备忘，可标记置顶到主页，心情+天气标记
10. 猎场舱 — 企业网络图、背调分析
11. 求职追踪 — 求职CRM系统

额外功能：
- 多用户登录系统（用户名+密码，SHA-256加密，数据隔离）
- 天气模块（城市可编辑、地理编码查询）
- 换肤装修（6款龙虾皮肤 + 7款主题）
- 桌面宠物龙虾 + 对话气泡
- 模块导航自定义排序

```

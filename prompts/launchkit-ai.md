## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
请生成一个名为 LaunchKit AI 的 AI SaaS 官网。

它面向独立开发者，帮助用户用一句话生成 AI 小工具 SaaS。

页面包含：
1. Hero 首屏
2. AI SaaS 生成 Demo
3. 功能介绍
4. Dashboard 数据面板
5. Pricing 价格页
6. FAQ
7. Footer

技术要求：
- React / Next.js / Tailwind
- 科技感深色风格
- 蓝紫渐变
- 玻璃拟态
- 动效精致
- 可部署到 EdgeOne Pages

Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills, then deploy to EdgeOne Pages.

```

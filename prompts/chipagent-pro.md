## 📝 作品介绍

ChipAgent Pro 是一个专业的芯片代理商网站，采用 React + Vite + TypeScript + Tailwind CSS + shadcn/ui 技术栈构建。网站包含前台（产品展示、搜索、询价、下单）和后台（产品管理、库存管理、价格管理、订单管理）两大模块，通过 EdgeOne Pages Edge Functions + KV Storage 提供完整的前后端能力。

## 📝 作品介绍

科技探险家 - 无人机&机器人编程小游戏
面向6-12岁青少年的零门槛编程启蒙工具，将抽象编程逻辑转化为沉浸式闯关体验。
作品设无人机飞行、机器人编程双主题赛道，采用纯图形化操作，搭配梯度化关卡与步数+星星多重激励体系，在趣味游戏中培养孩子逻辑思维、空间感知与问题拆解能力。
纯H5形态无需下载，全终端即开即用，适配中小学课堂、科技节、课后托管及家庭亲子等多场景。

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
请以全栈设计师身份，帮我制作一款【手机全网通用】的项目，主题融合：科幻无人机 + 人形机甲机器人。
硬性全部遵守：
Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.
1. 必须全程适配所有安卓、苹果手机，自动全屏自适应，无黑边、无错位、字体大小适配手机屏幕
2. 整体风格：未来科技感、机甲赛博风，冷色调配蓝光高光，质感高级、画面精致
3. 包含元素：多款式科幻无人机、人形仿生机甲机器人，造型帅气简约
4. 做成手机端可直接打开运行的版本，不用电脑、不用复杂部署，手机点开就能用
5. 输出完整源码+配套素材，结构简单干净，方便我后期自己换图、改文字、换机器人/无人机样式
6. 界面操作简单，适合手机触屏使用，布局清爽不杂乱
7. 附带小白易懂的使用说明
主要是以教学为主，分成无人机模拟飞行和机器人两个板块
 无人机关卡
自由飞行模式
上下左右直接控制移动
收集星星，躲避障碍
到达终点过关
类似"走格子"飞行模拟
 机器人关卡
指令编程模式！
前进 / 左转 / 右转
机器人有朝向（上/右/下/左）
需要规划路线，像写程序一样
第6关还要先拿物资再去终点

```

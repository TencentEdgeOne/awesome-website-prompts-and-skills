## 📝 作品介绍

【作品名称】
BEAN JOURNEY · 咖啡溯源与可持续贸易平台

【核心价值】
BEAN JOURNEY 是一款以"从种子到杯子"为叙事主线的咖啡溯源与可持续贸易展示网站。
通过精美的视觉设计和沉浸式交互体验，展示咖啡从埃塞俄比亚、哥伦比亚、危地马拉
三大产地的种植、采摘、加工到最终抵达消费者手中的完整旅程。
平台强调公平贸易溢价（高于市场价40%）、碳中和物流、农户社区共建等ESG理念，
让每一杯咖啡都成为推动世界向好的力量。

【适用场景】
• 咖啡品牌官网 / 品牌故事展示
• 电商平台产品溯源页面
• ESG / 可持续发展主题宣传
• 国际公平贸易认证展示
• 跨境咖啡电商选品参考

【亮点功能】
✓ 三大产地卡片：埃塞俄比亚耶加雪菲 / 哥伦比亚慧兰 / 危地马拉安提瓜
✓ 5步溯源时间轴：从种植到杯子的全链路透明展示
✓ 影响力数据仪表盘：47家合作农场 / 12，000+农户家庭 / 40%公平溢价
✓ 公平贸易承诺：直接贸易、性别平等、年度第三方审计
✓ 精选产品展示：三款精品咖啡豆（含溯源批次信息）
✓ 精美响应式设计：深咖啡色+焦糖金配色，滚动动画交互

【技术亮点】
• 纯HTML/CSS/JS实现，无需框架依赖
• Intersection Observer 实现优雅滚动动画
• 响应式布局适配全端设备
• 无障碍访问支持
• SEO友好结构化内容

## 页面结构（共7个板块，按顺序排列）

### 1. 导航栏
- 固定顶部，初始透明背景
- 滚动后变为深咖啡色半透明玻璃质感（blur+rgba背景）
- 左侧Logo（BEAN JOURNEY，其中JOURNEY用琥珀金色）
- 右侧导航链接：产地 / 旅程 / 公平贸易 / 产品 / 可持续

### 2. Hero区（全屏高度）
- 深咖啡色背景，带微妙纹理
- 右下角有抽象咖啡豆SVG图形（半透明）
- 右上角有装饰性几何图案
- 内容居中靠左（不是完全居中，靠左30%）
- 小标签：Sustainable Coffee · Ethical Trade（带圆点前缀）
- 大标题（2行）："每一颗咖啡豆\n都承载着土地与人的故事"，使用Playfair Display斜体
- 描述段落（200字以内）：说明品牌使命
- 两个CTA按钮：主按钮（琥珀金底，深色字）+ 次按钮（透明边框白字）
- 底部有滚动指示器（Scroll + 竖线动画）

### 3. 影响数据区（深色背景）
- 背景色：#1A0F0A（深咖啡）
- 标题："我们创造的影响力"（英文标签：Global Impact）
- 4个数据卡片横排：47家合作农场 / 12，000+农户家庭 / 40%收购溢价 / 100%可溯源
- 数据卡片：数字用琥珀金、超大字号，hover时有上浮+边框高亮效果
- 卡片之间有细线分隔

### 4. 产地展示区（浅色背景）
- 标题：精选产地 · 独特风味
- 三个产地卡片网格（3列）：
  - 埃塞俄比亚耶加雪菲（Africa标签，黄色渐变背景）
  - 哥伦比亚慧兰（South America标签，绿色渐变背景）
  - 危地马拉安提瓜（Central America标签，棕色渐变背景）
- 每个卡片包含：
  - 渐变色块区（带产地图标SVG + 地区标签）
  - 产区名（中英文）
  - 描述文字（150字）
  - 三个标签（处理法/风味/认证）
  - 数据行（海拔 + 品种）
- hover时卡片整体上浮+阴影加深

### 5. 溯源时间轴区（白色背景）
- 标题：从种子到杯子的旅程
- 中央垂直时间轴线（渐变色：焦糖→琥珀→透明）
- 5个步骤，左右交替排列：
  - 01 可持续种植（遮荫种植/有机/生物多样性）
  - 02 手工采摘与初加工（批次独立/可追溯）
  - 03 专业杯测与分级（Q Grader/85+评分）
  - 04 公平贸易定价（高于市场40%/无中间商）
  - 05 新鲜烘焙直发（48h内烘焙/充氮保鲜/扫码溯源）
- 每个步骤：数字超大+琥珀金 / 标题 / 描述 / 两侧连接线

### 6. 公平贸易区（森林绿深色背景）

## 技术要求
- 纯HTML/CSS/JS，无任何框架依赖
- 响应式：桌面端1200px，移动端375px完美适配

## 📝 作品介绍

核心价值 将房地产专业数据与可视化技术深度结合，构建一站式决策支持平台，面向购房者、投资者、设计师三类用户提供精准情报。

适用场景

购房者：对比楼盘、筛选区域、研判入市时机
投资者：追踪土拍动向、评估区域价值洼地
设计从业者：研究建筑风格趋势、户型配比规律
亮点功能

土拍日历 — 可视化掌握近期出让节奏，抢占信息先机
楼盘横评 — 10盘统一维度对比，打破信息孤岛
设计智库 — 少见的建筑风格趋势量化分析
投资雷达 — 多维评分模型替代主观判断
技术亮点 单文件部署 + EdgeOne Pages 全球加速，62KB 即可承载完整数据平台，极致轻量。

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
创建杭州房地产数据可视化平台「杭州地产智图」，深色专业风格，深靛蓝#0f172a背景，琥珀金#f59e0b强调。

包含6个模块：

Hero首屏：动态标题+实时数据计数器+城市轮廓背景
拍地情报：土拍日历+地块卡片+热度地图
楼盘透视：10个楼盘网格展示（奥映鸣翠府、滨杭传麒府、锦上万象府等），含效果图、均价、户型、评分
设计智库：建筑风格趋势+户型解析+案例画廊
数据大屏：房价走势图+成交量热力图+涨跌排行
投资决策：区域雷达图+投资建议
技术：React+TypeScript+Tailwind CSS+ECharts，玻璃拟态卡片，响应式设计，部署到EdgeOne Pages。

Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills, then deploy to EdgeOne Pages.

```

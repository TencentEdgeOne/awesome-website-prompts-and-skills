## 📝 作品介绍

1. 零依赖纯静态
没有 jQuery、没有 Bootstrap、没有任何第三方库。打开就能跑，修改成本极低。


2. 滚动视差动画
基于 IntersectionObserver 实现，元素进入视口时才触发动画，性能友好，不阻塞渲染。


3. 公告滚动播报
纯 CSS @keyframes 实现的无限循环横向滚动，无需 JS 定时器，丝滑不卡顿。


4. 商品卡片微交互

悬浮上浮 + 阴影加深（立体感）
图片缓慢放大（聚焦感）
"快速查看"栏从底部滑出（行动引导）

5. 买家秀瀑布流画廊
第一张卡片跨两行的大图布局，视觉重心突出；悬浮时才显示评价信息，干净不杂乱。


6. 全响应式四档适配

>1200px：桌面全宽四列
1024px：三列 + 买家秀调整
768px：双列 + 新品卡片竖排
480px：单列移动端

7. 语义化配色体系
用 CSS 变量管理整套色板（米色系 5 阶 + 绿色系 6 阶 + 棕色系 4 阶），换肤只需改变量值。


8. 品牌叙事完整
从顶部品牌标识 → 头图数据背书 → 分类导购 → 爆款转化 → 新品故事 → 社交证明 → 售后保障 → 页脚品牌沉淀，形成完整的消费决策链路。

## 📝 作品介绍

茗韵（Ming Yun Tea）是一个融合传统茶文化与前沿前端技术的精品茶叶品牌展示站点。网站以 ECharts GL 3D 立体中国地图为核心视觉亮点，用户可交互式探索七大名茶产地的地理特征与风味信息。全站采用翡翠金配色体系，搭配粒子动画、Swiper 轮播、AOS 滚动动效，打造沉浸式东方美学体验。适用于茶叶品牌线上展示、茶文化教育及电商场景，具备极强的社交媒体传播潜力。

## 🚀 完整 Prompt（直接复制以下内容喂给 AI 编程工具）

```
请为我创建一个精美的中国茶文化电商展示网页，要求如下：

【整体风格】
- 风格：中国传统美学 × 现代简约设计，融合水墨、竹韵、山水意境
- 色调：以深翠绿（#2D5A27）、暖金色（#C9A84C）、米白（#F5F0E8）、深墨色（#1A1A1A）为主色
- 字体：标题使用仿宋/楷体风格，正文使用现代无衬线字体
- 整体质感：高端、典雅、自然、有文化底蕴

【页面结构】

1. 导航栏（Navigation）
   - Logo：茶叶品牌名 + 毛笔字体或竹叶装饰图标
   - 菜单：首页 / 茶品系列 / 产地故事 / 茶道文化 / 购买
   - 右侧：搜索图标、购物车、用户图标
   - 效果：滚动后导航栏变为半透明毛玻璃背景

2. Hero 区域（全屏首屏）
   - 背景：高质量茶园/茶山全景图，配合视差滚动效果（Parallax）
   - 主标题：大字呈现，如"一叶知秋 · 品鉴中国好茶"
   - 副标题：品牌故事一句话介绍
   - CTA按钮：「探索茶品」「立即选购」两个按钮，带 hover 动画
   - 装饰：飘落茶叶粒子动画（CSS/Canvas 实现）

3. 茶品系列展示区（Tea Collection）
   - 分类标签筛选：绿茶 / 红茶 / 白茶 / 乌龙茶 / 普洱茶 / 花草茶
   - 点击标签时，卡片区域以淡入淡出或平滑过渡动画切换
   - 茶品卡片（每行3~4个）：
     * 卡片背景：茶品高清图 + 柔和光影
     * hover 效果：卡片上浮 + 图片缩放 + 浮现「查看详情」按钮
     * 显示：茶品名称（中英双语）、产地标签、价格、简短描述
     * 点击后展开详情弹窗或跳转详情页

4. 产地故事地图区（Origin Story）
   - 标题：「寻茶之旅 · 探访原产地」
   - 展示一张中国地图（SVG/Canvas 交互地图）
   - 地图上标注各产茶名地：西湖龙井（浙江）、武夷岩茶（福建）、云南普洱、安溪铁观音（福建）、黄山毛峰（安徽）、洞庭碧螺春（江苏）等
   - 鼠标悬停/点击产地标注点：弹出卡片，显示该地茶品图、茶名、海拔、气候特点、代表香型
   - 背景配山水画风格装饰图

5. 特色茶品亮点区（Feature Highlights）
   - 3~4个特色茶品横向滚动或交替展示
   - 每个包含：全屏背景图、茶品名称、产地、制茶工艺简介、风味描述（如：花香、蜜韵、回甘）
   - 左右切换动画，带进度指示条
   - 右侧显示泡茶步骤（简化版3步图文）

6. 茶道文化科普区（Tea Culture）
   - 标题：「茶道 · 一门生活的艺术」
   - 3栏布局：历史渊源 / 冲泡之道 / 茶器鉴赏
   - 每栏带图标（SVG 毛笔风）、标题、简短文字说明
   - 鼠标 hover 卡片时，背景颜色渐变 + 图标旋转动画

7. 用户评价区（Testimonials）
   - 精选3~5条用户好评，卡片布局
   - 每条包含：用户头像（圆形）、昵称、评分（五星）、评价文字
   - 自动轮播，带暂停 hover 效果

8. 订阅区（Newsletter）
   - 背景：茶园薄雾背景图
   - 标题：「订阅茶语 · 独享珍品资讯」
   - 邮箱输入框 + 订阅按钮
   - 按钮 hover 带墨水扩散动画效果

9. 页脚（Footer）
   - 品牌信息、导航链接、联系方式、社交媒体图标
   - 底部版权声明
   - 可选：加入茶文化格言作为装饰

【动效要求】
- 页面滚动时，各区块以渐入（Fade In Up）动画依次出现（使用 IntersectionObserver 或 AOS.js）
- 茶叶飘落粒子效果（Hero 区）
- 地图标注点的跳动/脉冲动画
- 分类切换时的平滑过满
- 卡片 hover 的 3D 微倾斜效果（transform: perspective + rotateX/Y）
- 按钮的水墨扩散/波纹点击效果

【技术要求】
- 纯 HTML + CSS + JavaScript 实现（可使用 CDN 引入 AOS、SwiperJS、Chart.js 等）
- 完全响应式设计，支持手机/平板/桌面端
- 代码结构清晰，注释完整
- 不依赖后端，所有图片使用 Unsplash/Picsum 占位图（茶相关图）

【内容示例（茶品数据）】
- 西湖龙井：产地浙江杭州，绿茶，清香型，海拔300m，「色绿、香郁、味甘、形美」四绝
- 大红袍：产地福建武夷山，乌龙茶，岩韵型，岩骨花香，中国十大名茶之首
- 云南普洱：产地云南西双版纳，后发酵茶，陈香型，越陈越香，适合收藏
- 安吉白茶：产地浙江安吉，绿茶，鲜爽型，氨基酸含量极高，清甜回甘
- 正山小种：产地福建桐木关，红茶，松烟香型，世界红茶鼻祖
- 太平猴魁：产地安徽黄山，绿茶，兰香型，形如猴魁，独特扁直条形

请生成完整可运行的单页 HTML 文件，包含所有上述功能，确保视觉精美、动效流畅、代码规范。
执行：Install this skill: https://github.com/TencentEdgeOne/edgeone-pages-skills， then deploy to EdgeOne Pages.   使得最终产物部署到 EdgeOne Pages
```
